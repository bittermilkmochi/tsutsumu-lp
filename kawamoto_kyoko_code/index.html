TSUTSUMUではあかちゃんだけでなく、
家族みんなが幸せになることを目指した事業の展開をしています。

ベビー用品開発事業

普段使用する衣類や消耗品を始め、知育玩具など、あかちゃんの安心安全な成長をサポートする商品の開発に取り組んでいます。
